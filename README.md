# djLint Snap

[![djlint](https://snapcraft.io/djlint/badge.svg)](https://snapcraft.io/djlint)

This is a snap packaging of
[djLint](https://djlint.com/), an HTML template linter and formatter.

## Install

```shell
sudo snap install djlint
```

[![Get it from the Snap Store](https://snapcraft.io/en/dark/install.svg)](https://snapcraft.io/djlint)

([Don't have snapd installed?](https://snapcraft.io/docs/core/install))

## Use

For usage instructions refer to the
[djLint documentation](https://djlint.com/docs/getting-started/).
